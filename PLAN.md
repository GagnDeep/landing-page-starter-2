## Calculation Engine Logic & Formulas

### 1. Self-Employment (SE) Tax Calculation:
$$\text{Net SE Earnings} = \text{Gross 1099 Profit} \times 0.9235$$
$$\text{Social Security Tax (12.4\%)} = \min(\text{Net SE Earnings}, \text{SS Wage Limit}) \times 0.124$$
$$\text{Medicare Tax (2.9\%)} = \text{Net SE Earnings} \times 0.029$$
$$\text{Total SE Tax} = \text{Social Security Tax} + \text{Medicare Tax}$$

### 2. Above-the-Line Deductions:
$$\text{Deductible SE Tax Portion} = \text{Total SE Tax} \times 0.50$$
$$\text{Adjusted Gross Income (AGI)} = \text{Gross Income} - \text{Total Deductions} - \text{Deductible SE Tax Portion}$$

### 3. Federal Income Taxable Income:
$$\text{Taxable Income} = \max(0, \text{AGI} - \text{Standard Deduction} - \text{QBI Deduction})$$
$$\text{QBI Deduction} = \min(0.20 \times (\text{Gross 1099 Profit} - \text{Deductible SE Tax}), 0.20 \times \text{Taxable Income before QBI})$$
