# Current State

## Project Overview
The Boho Salon is a premier beauty and nail destination in Sector 17, Chandigarh, known for chrome gel nails, advanced curly haircuts, and a refined bridal-NRI experience. This project establishes a digital presence that mirrors the salon’s boho-modern, artistic, and welcoming brand identity, prioritizing high-end aesthetics and seamless user navigation for a diverse, sophisticated clientele.
