# Careers Page Layout Structure

1. **Header:** "Join Our Team".
2. **Culture/Vibe Statement:** Short paragraph about working at Aura.
3. **Open Roles List:** Clean list of available positions (Tailors, Stylists, Retail Staff).
4. **Benefits/Perks:** Grid of reasons to work there.
5. **General Application CTA:** Fallback for unsolicited applications.
