# Careers Page Layout Architecture

## 1. Hero (`CareersHero`)
- **Intent:** "Join the midnight magic."
- **Rhythm:** High energy, warm imagery.

## 2. Why Work With Us (`CareersBenefits`)
- **Intent:** Sell the culture.
- **Rhythm:** 3-column typographic grid.

## 3. Day in the Life (`CareersLife`)
- **Intent:** Realistic expectation setting.
- **Rhythm:** Scrolling image gallery with captions.

## 4. Open Positions (`CareersList`)
- **Intent:** The job board.
- **Rhythm:** Clean table or list layout. Hover effects reveal "Apply" buttons.
