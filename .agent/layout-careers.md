# Careers Page Layout Map

## 1. Hero (`hero`)
**Intent:** Attract top-tier hospitality and culinary talent.
**Rhythm:** Dynamic image of the team in action, inspiring headline.

## 2. Culture & Benefits (`culture`)
**Intent:** Explain why working at Oasis is rewarding.
**Rhythm:** 3-column icon and text grid.

## 3. Open Positions (`open-positions`)
**Intent:** List current job openings.
**Rhythm:** Clean list layout with expandable details or links to individual job descriptions.

## 4. Application CTA (`apply-cta`)
**Intent:** General application drop-off for future openings.
**Rhythm:** Simple, centered call to action.
