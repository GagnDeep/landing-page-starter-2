# Layout: Careers Page
**Rhythm**: Inspiring, dynamic, focused on team culture and artistry.

1.  **Global Navigation**: Sticky, translucent header.
2.  **Careers Hero**: Dynamic video background showing the bustling kitchen/studio.
3.  **Culture Intro**: Large, centered typography stating the brand's philosophy on talent.
4.  **Why Join Us Grid**: 3-column grid highlighting benefits (e.g., creativity, benefits, environment).
5.  **A Day in the Life**: Horizontal scrolling image gallery of team members at work.
6.  **Core Values (Internal)**: Split layout. Text heavy on one side, abstract brand imagery on the other.
7.  **Testimonial from Team**: Large pull quote on a muted background.
8.  **Diversity & Inclusion Statement**: Narrow, centered text column.
9.  **Open Positions Header**: Bold, left-aligned typography.
10. **Department Filter**: Horizontal list of tags (e.g., Pastry, Admin, Delivery).
11. **Job List (Role 1)**: Expandable row layout. Job title, location, type.
12. **Job List (Role 2)**: Expandable row layout.
13. **Job List (Role 3)**: Expandable row layout.
14. **Job List (Role 4)**: Expandable row layout.
15. **General Application**: Callout box for speculative applications.
16. **The Hiring Process**: 4-step visual timeline.
17. **Apprenticeship/Internship Info**: Split layout highlighting learning opportunities.
18. **Studio Benefits Full List**: Dense 4-column bulleted list.
19. **Final Push CTA**: Image background with overlay text encouraging application.
20. **Global Footer**: Centered, clean link directory.
