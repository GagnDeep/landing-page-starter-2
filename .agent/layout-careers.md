# Layout: Careers Page

A page for recruiting talent (second shooters, editors, assistants).

## Sections

1.  **Hero Section:** "Join the Studio". Behind-the-scenes image of the team working.
2.  **Studio Culture:** Why work with Studio Sanjay Arts? Emphasize the learning environment and high standards.
3.  **Open Positions:** A list of current openings (e.g., Lead Editor, Second Photographer). Expandable sections with requirements.
4.  **Application Form:** A form to submit resume, portfolio links, and a brief intro.
5.  **Freelance Roster:** Information for freelancers who want to be added to the studio's roster for busy seasons.
