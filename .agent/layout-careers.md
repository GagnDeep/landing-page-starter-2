# Layout Intent: Careers Page

1. **Hero (Join the Legacy):** Showcasing the team in action.
2. **Culture & Values:** Text blocks describing the work environment and expectations.
3. **Benefits:** Grid of perks (e.g., training, insurance, meals).
4. **Open Positions:** Accordion or list of current job openings.
5. **Application Form:** A simple form or instructions on how to apply.
