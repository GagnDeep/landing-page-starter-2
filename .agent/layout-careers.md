# Layout Blueprint: Careers Page (`/careers`)

## Goal
To recruit high-quality, patient instructors and staff who align with the "Calm, Methodical, Safe" philosophy.

## Section Architecture (15-20 Blocks)

1.  **Global Navigation (Header):** Standard global component.
2.  **Hero Section:** "Join the Team. Shape Safe Drivers." Background of instructors.
3.  **Why Work With Us:** Value proposition for employees (respect, good vehicles, steady work).
4.  **Our Core Values:** Reiteration of patience, safety, and professionalism.
5.  **Instructor Requirements:** Clear list of mandatory qualifications (licenses, background checks).
6.  **The "Armaan Standard":** What separates an Armaan instructor from the rest (pedagogy training).
7.  **Benefits/Perks:** e.g., flexible hours, performance bonuses, well-maintained cars.
8.  **Current Openings List:** Dynamic list or static blocks for open roles (e.g., "Lead Instructor", "Admin Assistant").
9.  **Job Details Accordion/Modal:** Click to view full description for a specific role.
10. **Application Form:** Direct upload for Resume/CV and basic details.
11. **Employee Testimonial:** Quote from a current instructor about the work environment.
12. **The Hiring Process:** Timeline (Apply -> Interview -> Trial -> Onboarding).
13. **Diversity & Inclusion Statement:** Commitment to fair hiring.
14. **Contact for HR:** Specific email or phone for application queries.
15. **Global Footer:** Standard global component.
