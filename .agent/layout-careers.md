# Careers Page Layout Blueprint

## 1. Hero
- **Layout:** Action-oriented imagery of the kitchen staff. "Join Our Family."

## 2. Culture & Values
- **Layout:** 3-column icon and text grid explaining why to work here.

## 3. Open Roles
- **Layout:** A list or table of available positions (e.g., Sous Chef, Event Coordinator), with expandable details.

## 4. Application Process
- **Layout:** 3-step horizontal process bar.

## 5. General Application
- **Layout:** A small form or email link for unsolicited resumes.
