# Blog Page Layout Structure (Editorial & Style Guides)

1. **Page Header**: "The Heritage Journal" - Title and brief description.
2. **Featured Article**: Large hero-style card for the latest or most important post.
3. **Category Filter**: Elegant text-based navigation (e.g., Bridal, Trends, Heritage).
4. **Article Grid**: Clean, spaced-out grid of recent articles with portrait imagery.
5. **Newsletter Sign-up**: Inline subscription box.
6. **Footer**: Standard expansive footer.
