# Layout Intent: Blog Page (Journal)

1. **Hero (The Journal):** Elegant, magazine-style header.
2. **Featured Article:** Large leading card taking up significant visual space.
3. **Category Filter:** Clean, horizontal scrollable list of topics (e.g., Real Weddings, Menu Ideas, Planning).
4. **Article Grid:** 3-column grid of standard article cards.
5. **Pagination:** Minimalist page numbers or "Load More" button.
6. **Newsletter Sign-up:** Integrated within the grid or at the bottom.
