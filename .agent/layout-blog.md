# Layout: Blog Page
**Rhythm**: Editorial, magazine-like, image-forward.

1.  **Global Navigation**: Sticky, translucent header.
2.  **Blog Hero / Featured Article**: Full-bleed image with large overlay typography, occupying 70vh.
3.  **Category Filter**: Sticky horizontal scrolling list of minimal text links just below the hero.
4.  **Latest Articles Grid (Top)**: 2-column asymmetric grid. One large article, one smaller.
5.  **Newsletter Inline Promo**: Solid primary color block cutting across the grid.
6.  **Article Grid (Standard)**: 3-column even grid. Image dominant, subtle typography below.
7.  **Editorial Spotlight**: Split layout. Dark background, large elegant typography left, portrait image right.
8.  **Article Grid (Continued)**: 3-column even grid.
9.  **Quote / Inspiration Block**: Full width, large italicized serif text on a muted background.
10. **Wedding Spotlight Feature**: Large, wide panoramic image with text overlay on the bottom left.
11. **Flavor Profiles Series**: Horizontal scrolling carousel of cards.
12. **Article Grid (Continued)**: 2-column grid, larger images.
13. **Behind the Scenes Video**: Full-width video block.
14. **Article Grid (Continued)**: 4-column tight grid for shorter, quick-read pieces.
15. **Most Popular Articles**: Sidebar layout. Content left, list of top 5 right.
16. **Guest Contributor Feature**: Split layout highlighting a specific author or partner.
17. **Pagination/Load More**: Elegant, minimalist button centered below the grid.
18. **Instagram Feed Teaser**: 6-image tight grid spanning full width.
19. **Final Newsletter Opt-in**: Large, spacious block.
20. **Global Footer**: Centered, clean link directory.
