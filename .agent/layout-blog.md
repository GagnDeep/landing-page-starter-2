# Blog Page Layout Rhythm

Content marketing to drive local SEO and engage the community.

## 1. Hero / Featured Post
- **Intent:** Highlight the latest or most important article.

## 2. Category Filters
- **Intent:** Allow users to sort by themes (e.g., Party Planning, Flavor Profiles).

## 3. Article Grid
- **Intent:** A masonry or standard grid of recent posts.

## 4. Newsletter Signup
- **Intent:** Capture emails for local promotions.
