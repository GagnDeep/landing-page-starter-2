# Blog Page Layout Structure (The Journal)

**Goal:** An editorial destination for style advice, fabric education, and atelier news.

1. **Header (Global):** Same as home.
2. **Hero Section (The Journal):** A minimal header with the title and a short description.
3. **Featured Article:** The most recent or important post. Takes up significant screen real estate. Large image, prominent title, excerpt.
4. **Category Navigation:** A sticky, horizontal, elegant list of categories (e.g., "Style", "Craft", "Atelier News").
5. **Article Grid:** A 2-or-3 column grid of articles. High reliance on typography and image ratios, avoiding heavy borders or drop shadows.
6. **Newsletter Interstitial:** A break in the grid to encourage subscribing for updates.
7. **Pagination/Load More:** A delicate ghost button or elegant numeric pagination.
8. **Footer (Global):** Same as home.
