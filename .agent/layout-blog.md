# Blog / Journal Page Layout Blueprint

## 1. Hero / Featured Post
- **Layout:** Large banner featuring the most recent or important article. Overlaid text or split layout.

## 2. Categories/Filters
- **Layout:** A horizontal scrollable list of pill-shaped buttons (e.g., "Weddings", "Recipes", "Planning Tips").

## 3. Post Grid
- **Layout:** 3-column masonry or standard grid of article cards (Image, Date, Title, Excerpt).

## 4. Newsletter Sign-up
- **Layout:** Inline banner to subscribe for updates.

## 5. Pagination/Load More
- **Layout:** Simple button or numbered pagination at the bottom.
