# Layout Documentation: Blog Page

## Intent
Share insights on style, fabric care, and the tailoring world. The layout should feel like a premium editorial magazine (e.g., GQ or The Rake), not a standard WordPress feed.

## Sections
1. **Featured Article:** Large hero image, dominant headline, excerpt.
2. **Category Navigation:** Elegant, subtle text links (e.g., "Style Guides", "Fabric Focus", "Atelier News").
3. **Article Grid:** 2 or 3 column masonry or standard grid. Focus on beautiful imagery and typography.
4. **Newsletter Signup:** "Join our Sartorial Newsletter." Inline, elegant input.
