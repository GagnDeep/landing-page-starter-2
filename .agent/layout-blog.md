# Layout: Blog (Journal) Page

The Blog page serves as a portfolio of full stories and a hub for wedding advice, formatted like a high-end editorial magazine.

## Sections

1.  **Hero Section:** "The Journal". A featured, large-format post highlighting a spectacular recent wedding.
2.  **Categories Filter:** A clean horizontal scroll or pill-based navigation (e.g., Real Weddings, Planning Tips, Engagement Sessions).
3.  **Latest Stories (Grid):** A responsive grid (1 column mobile, 2-3 columns desktop). Magazine-style cards with large images, elegant typography for titles, date, and category.
4.  **Featured Category (e.g., Destination Weddings):** A highlighted horizontal section breaking the grid rhythm.
5.  **Newsletter Signup:** A minimalist block encouraging users to subscribe for inspiration.
6.  **Pagination / Load More:** Elegant button to view older posts.
