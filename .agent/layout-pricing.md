# Layout: Pricing Page
**Rhythm**: Transparent, clear, yet maintaining the luxury aesthetic. No aggressive sales tactics.

1.  **Global Navigation**: Sticky, translucent header.
2.  **Pricing Hero**: Clean, minimal typographic hero. No distracting background image.
3.  **Pricing Philosophy**: Short, centered text block explaining the value of custom artistry.
4.  **Tier 1 (Signature)**: Large, elegant card layout. Left side text, right side feature list.
5.  **Tier 2 (Custom/Premium)**: Highlighted card layout (e.g., dark mode styling). Slightly elevated.
6.  **Tier 3 (Event/Sculpted)**: Large, elegant card layout, matching Tier 1 style.
7.  **What's Included (All Tiers)**: 3-column grid of minimalist checkmarks and text.
8.  **Base Pricing Table**: Detailed tabular layout for standard sizes/servings.
9.  **Flavor Upcharges**: Simple list layout with dotted leaders bridging item to price.
10. **Design Complexity Matrix**: 2x2 visual grid explaining how design impacts cost.
11. **Tasting Box Purchase**: Split layout. Image of tasting box, CTA to purchase.
12. **Delivery Fees**: Map or region-based visual list.
13. **Setup Fees**: Short explanatory text block with subtle iconography.
14. **Stand Rentals**: Grid of available stands with daily/event rental prices.
15. **Payment Terms & Schedule**: Visual timeline showing deposit and final payment milestones.
16. **Cancellation/Rescheduling Policy**: Muted background, narrow text column for readability.
17. **FAQ (Pricing Specific)**: Accordion layout, directly addressing budget concerns.
18. **Budget Calculator Teaser**: Interactive element placeholder.
19. **Consultation CTA**: Large, warm, welcoming block encouraging dialogue rather than immediate purchase.
20. **Global Footer**: Centered, clean link directory.
