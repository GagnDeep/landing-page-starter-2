# Pricing/Investment Page Layout Map

## 1. Hero (`hero`)
**Intent:** Frame the pricing as an investment in a flawless experience.
**Rhythm:** Understated elegance, soft background, focusing on the word "Investment".

## 2. Philosophy on Value (`value-philosophy`)
**Intent:** Explain why the service commands a premium.
**Rhythm:** Centered text block with generous padding.

## 3. Sample Packages (`sample-packages`)
**Intent:** Provide baseline expectations for different event tiers.
**Rhythm:** 3-column card layout, emphasizing the middle "Signature" package with a subtle border or badge.

## 4. What's Included (`whats-included`)
**Intent:** Detail the comprehensive nature of the service.
**Rhythm:** 2-column list with checkmarks, using the muted background.

## 5. Custom Quote CTA (`cta`)
**Intent:** Drive users to request a bespoke proposal.
**Rhythm:** High contrast block with a direct call to action.
