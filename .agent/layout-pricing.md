# Pricing / Menu Page Layout Architecture

## 1. Hero (`PricingHero`)
- **Intent:** Set expectations of premium quality.
- **Rhythm:** Editorial header. Simple, centered.

## 2. Tier 1: Classic Cakes (`PricingClassic`)
- **Intent:** Everyday celebrations.
- **Rhythm:** Clean list layout. Typography-heavy, minimal imagery.

## 3. Tier 2: Signature Creations (`PricingSignature`)
- **Intent:** The core premium offering.
- **Rhythm:** Grid of cards, but elegant. Large price typography.

## 4. Tier 3: Custom & Wedding (`PricingCustom`)
- **Intent:** High ticket items requiring consultation.
- **Rhythm:** Highlight section. Distinct background color.

## 5. Add-ons & Gifts (`PricingAddons`)
- **Intent:** Upsell.
- **Rhythm:** Tight 4-column grid.

## 6. FAQ Mini (`PricingFAQ`)
- **Intent:** Address immediate buying hesitations.
- **Rhythm:** Accordion style, clean and minimal.
