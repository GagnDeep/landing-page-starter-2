# Pricing Page Layout Rhythm

Transparency and clarity are key here.

## 1. Hero Section
- **Intent:** Set expectations that custom work requires custom quotes, but base prices are provided.

## 2. Base Pricing Tiers
- **Intent:** Simple cards or a table showing starting prices based on size/tiers.

## 3. Customization Add-ons
- **Intent:** List common add-ons (fondant figures, specialized flavors) and their starting costs.

## 4. Request a Quote Form
- **Intent:** The primary conversion action for this page.
