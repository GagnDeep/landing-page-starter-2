# Pricing Page Layout Blueprint

## 1. Hero
- **Layout:** Simple, clear header. "Transparent, Tailored Pricing."

## 2. The Packages
- **Layout:** 3-column grid of Pricing Cards.
- **Visual:** Middle card highlighted with a primary border/background as the "Signature" tier.

## 3. A La Carte/Add-ons
- **Layout:** A clean, multi-column list or table detailing specific add-ons (Live Tandoor Station, Premium Bar Setup).

## 4. What's Included
- **Layout:** A large checklist section detailing standard inclusions (staff, standard cutlery, cleanup).

## 5. FAQ (Pricing Specific)
- **Layout:** Accordion for common budget questions.

## 6. CTA
- **Layout:** Custom quote request button.
