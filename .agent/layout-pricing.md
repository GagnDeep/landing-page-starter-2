# Pricing / Consultation Page Layout

1. **Hero Section**
   - Clear messaging on transparent, premium pricing.
2. **Initial Consultation Tier**
   - Details of what the first assessment includes.
3. **Session Packages**
   - Details for block bookings (e.g., Paralysis Rehab 10-session pack).
4. **NRI Care Packages**
   - Specific pricing structures for remote monitoring and intensive local care for NRI families.
5. **Insurance Information**
   - Details on claims and accepted providers.
6. **FAQ on Billing**
   - Short accordion for payment-related questions.
7. **Contact / Inquiry Form**
