# Layout Blueprint: Pricing Page

## Intent
To present catering packages clearly and transparently, guiding users toward the best option for their event size while communicating the premium value of the service.

## Sections (20+)
1. **Header/Navigation:** Standard site header.
2. **Hero Header:** Clear, straightforward title like "Transparent Packages for Every Celebration."
3. **Pricing Philosophy:** A short explanation of what goes into the pricing (quality ingredients, expert staff).
4. **Package Toggle:** A toggle switch (e.g., "Up to 500 Guests" vs "500+ Guests") or event type toggle.
5. **Pricing Cards Container:** A grid layout for the pricing tiers.
6. **Tier 1 Card (The Classic Feast):** Base package, price per plate, feature list.
7. **Tier 2 Card (The Royal Punjabi):** Highlighted/Recommended package, price, expanded feature list.
8. **Tier 3 Card (The Imperial Banquet):** Premium package, price, full luxury feature list.
9. **Add-on Services Title:** Section header for extras.
10. **Add-on 1 (Live Chaat Counter):** Description and pricing.
11. **Add-on 2 (Dessert Bar):** Description and pricing.
12. **Add-on 3 (Premium Beverage Station):** Description and pricing.
13. **Custom Menu CTA:** A banner offering bespoke menu design for unique needs.
14. **What's Always Included:** A grid of features included in *every* package (e.g., standard tableware, basic staff).
15. **Tasting Session Info:** Details on how to book a tasting before committing.
16. **Payment Terms:** Clear breakdown of advance payments, cancellation policies, etc.
17. **FAQ (Pricing Specific):** Accordion for questions like "Are there hidden charges?"
18. **Testimonial (Value focused):** A quote emphasizing that the service was "worth every penny."
19. **Contact CTA:** "Need help choosing? Talk to our event planners."
20. **Download Pricing PDF:** Option to save the pricing sheet.
21. **Footer:** Standard site footer.

## Visual Rhythm
Clean, tabular, and highly organized. The pricing cards are the visual anchor, using subtle depth (shadows, borders) to highlight the recommended tier, followed by easily digestible lists for add-ons and terms.
