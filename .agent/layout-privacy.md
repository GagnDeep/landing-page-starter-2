# Privacy Policy Layout Structure

**Goal:** Present privacy information clearly and legibly.

1. **Header (Global):** Same as home.
2. **Hero Section (Privacy Policy):** Minimal text, last updated date.
3. **Table of Contents (Optional):** Sticky sidebar for navigation.
4. **Policy Content:** Narrow, readable single column. Strong typographic hierarchy.
5. **Footer (Global):** Same as home.
