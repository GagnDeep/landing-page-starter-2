# Privacy Policy Page Layout Map

**Goal:** Standard legal page. Clean, legible, and unobtrusive.

## Section 1: Header
- **Visuals:** Minimalist.
- **Structure:** "Privacy Policy". Last updated date.

## Section 2: Content Body
- **Visuals:** Long-form text block with clear typography (Lato).
- **Structure:** Sections covering data collection, usage, third-party sharing, cookies, and user rights.
