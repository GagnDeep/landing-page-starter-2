# Agent Memory

**Project:** Capital Driving School

## Brand & Design Guidelines
- **Core Identity:** Calm, patient, professional, and confident.
- **Aesthetic:** High-end, modern service studio.
- **Dark Mode:** Visually rich, deep, balanced tones (no simple black-and-white swaps).
- **Typography:** Approachable yet authoritative (avoiding generic defaults).
- **Layout:** Prioritize visual rhythm and user journey over content density.
