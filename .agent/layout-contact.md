# Layout Intent: Contact Page

1. **Hero (Let's Connect):** Welcoming image, clear headline.
2. **Contact Form (Left):** Elegant form inputs (Name, Date, Venue, Guest Count, Message).
3. **Contact Info (Right):** Address, Phone numbers, Email, Business Hours.
4. **Map Integration:** A stylized, branded map or elegant static image of the Patiala location.
5. **Tasting Session Info:** Small block explaining how to book a tasting.
