# Contact Page Layout Architecture

## 1. Hero (`ContactHero`)
- **Intent:** "We're always awake."
- **Rhythm:** Split screen.

## 2. The Form (`ContactForm`)
- **Intent:** Primary contact method.
- **Rhythm:** Left side. Minimalist input fields, thin borders.

## 3. Direct Info (`ContactInfo`)
- **Intent:** Phone, email, address.
- **Rhythm:** Right side. Large, selectable typography.

## 4. Map/Location (`ContactMap`)
- **Intent:** Physical presence.
- **Rhythm:** Full width, beautifully styled (monochrome/tinted) map.
