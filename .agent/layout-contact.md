# Layout: Contact Page
**Rhythm**: Welcoming, professional, clear. Split focus between direct info and inquiry forms.

1.  **Global Navigation**: Sticky, translucent header.
2.  **Contact Hero**: Split layout. Large elegant typography on the left, warm welcoming image on the right.
3.  **Direct Contact Info Bar**: 3-column horizontal strip (Email, Phone, Studio Hours).
4.  **Inquiry Form Intro**: Centered, warm explanatory text about the response time.
5.  **Form Section: Personal Details**: 2-column grid for Name, Email, Phone.
6.  **Form Section: Event Details**: Date picker, Location input, Guest Count dropdown.
7.  **Form Section: Vision**: Large textarea for design ideas.
8.  **Form Section: File Upload**: Minimalist drag-and-drop zone for inspiration images.
9.  **Form Submit**: Elegant, full-width button within the form container.
10. **Alternate Contact (Vendors/Press)**: Smaller, secondary text block linking to specific emails.
11. **Studio Location Header**: Centered typography.
12. **Interactive Map**: Full-width or large boxed map component styled to brand colors.
13. **Parking/Arrival Instructions**: Narrow text column below the map.
14. **Tasting Appointments Info**: Split layout. Image left, booking details right.
15. **Social Media Links**: Large, elegant icon grid.
16. **FAQ Teaser**: 2-3 common questions specifically related to getting started.
17. **Response Timeline Graphic**: Visual step-by-step of what happens after submitting.
18. **Newsletter Opt-in**: Subtle, secondary placement near the bottom.
19. **Closing Image**: Full-bleed, calming image.
20. **Global Footer**: Centered, clean link directory.
