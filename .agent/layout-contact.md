# Contact Page Layout Map

## 1. Hero (`hero`)
**Intent:** Invite the user to begin their journey.
**Rhythm:** Elegant typography, welcoming tone.

## 2. Contact Form (`contact-form`)
**Intent:** Capture necessary details for a consultation (Date, Venue, Guest Count).
**Rhythm:** Clean, spacious form fields with a sophisticated styling (e.g., bottom borders only).

## 3. Direct Contact Info (`direct-info`)
**Intent:** Provide alternative contact methods for immediate needs.
**Rhythm:** 2-column layout beside the form, listing phone, email, and office address.

## 4. Office Location/Map (`location`)
**Intent:** Show the physical presence (if applicable).
**Rhythm:** Full-width stylized map or an elegant image of the studio exterior.
