# Layout Documentation: Contact Page

## Intent
Facilitate easy communication and booking. The form must feel premium, not like a generic data collection tool.

## Sections
1. **Hero:** Split layout. Left: "Get in Touch." Right: Image of the atelier door or a welcoming detail.
2. **Contact Form:** Minimalist fields. Floating labels or very subtle borders. Use specific tailoring language (e.g., "What garment are you envisioning?").
3. **Direct Info:** Phone number, email, physical address (with an elegant map).
4. **Hours of Operation:** Clear typographic list.
