# Layout Documentation: Contact Page (`/contact`)

## Structural Intent & Visual Rhythm
The Contact page should feel personal and accessible. It uses a clean, two-column split layout to balance the utility of a form with the warmth of the bakery's location and contact details.

## Sections (20 Named Layout Blocks)
1.  **`Contact-01-GlobalHeader`**: Standard elegant navigation bar.
2.  **`Contact-02-PageHero`**: Simple, inviting title ("Get in Touch" or "Visit Us") with a subtle background texture.
3.  **`Contact-03-SplitLayoutContainer`**: Main structural block, typically 50/50 split on desktop.
4.  **`Contact-04-ContactDetailsPanel`**: Left or right column containing textual contact information.
5.  **`Contact-05-AddressBlock`**: Clear typography listing the physical address, potentially with a small map icon.
6.  **`Contact-06-HoursBlock`**: A formatted list of opening hours for each day of the week.
7.  **`Contact-07-PhoneEmailBlock`**: Clickable links for phone numbers and email addresses.
8.  **`Contact-08-SocialLinksRow`**: Minimalist icons linking to Instagram, Facebook, etc.
9.  **`Contact-09-InquiryFormPanel`**: The column containing the contact form.
10. **`Contact-10-FormIntroduction`**: Brief text instructing the user on what type of inquiries the form is best for.
11. **`Contact-11-InputName`**: Text input field with floating or clean top label.
12. **`Contact-12-InputEmail`**: Email input field.
13. **`Contact-13-SelectInquiryType`**: Dropdown menu (e.g., General, Custom Cake, Wholesale).
14. **`Contact-14-InputMessage`**: Large text area for the user's message.
15. **`Contact-15-SubmitButton`**: Prominent call to action matching the brand's primary button style.
16. **`Contact-16-FormSuccessMessage`**: Hidden state that displays an elegant thank-you message after submission.
17. **`Contact-17-MapEmbed`**: A full-width or large block featuring an embedded Google Map, styled to match the brand colors if possible.
18. **`Contact-18-ParkingInfo`**: Small text block below the map explaining parking availability.
19. **`Contact-19-GlobalFooterMain`**: Standard footer structure.
20. **`Contact-20-GlobalFooterLegal`**: Standard legal footer strip.
