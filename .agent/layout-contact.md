# Layout Blueprint: Inquiry Page (`/contact`)

*Intent: A highly curated, white-glove intake process.*

## 1. Inquiry Hero
- **Intent**: Set an inviting but exclusive tone.
- **Visual Rhythm**: Split screen: elegant image on one side, intake form on the other.

## 2. The Form (Intake)
- **Intent**: Gather crucial qualifying details.
- **Visual Rhythm**: Floating labels, elegant thin-line inputs. Multi-step if necessary for elegance.

## 3. Direct Contact Info
- **Intent**: Provide alternative contact methods for press or partners.
- **Visual Rhythm**: Small, beautifully typeset block below the form.

## 4. Office Locations
- **Intent**: Show physical presence or bases of operation.
- **Visual Rhythm**: Simple text list of cities.
