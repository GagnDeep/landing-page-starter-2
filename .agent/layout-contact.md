# Contact Page Layout Structure

1. **Page Header**: "Get in Touch"
2. **Boutique Information**: Address in Chandigarh, operating hours, and direct phone/email.
3. **Interactive Map**: A stylized, muted map showing the boutique location.
4. **Contact Form**: An elegant form for general inquiries or appointment requests.
5. **Styling Consultation CTA**: Specialized link for bridal appointments.
6. **Footer**: Standard expansive footer.
