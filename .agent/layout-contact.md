# Layout intent for A2Zee Events - Contact Page

1. **Global Header**
   - *Layout intent:* Consistent navigation.
   - *Visual rhythm:* Solid header.

2. **Hero Section (Let's Begin)**
   - *Layout intent:* Split layout. Text and a beautiful, inviting image side-by-side.
   - *Visual rhythm:* Very balanced. The image should feel welcoming (e.g., a detail shot of two glasses of champagne).

3. **Direct Contact Information**
   - *Layout intent:* A block showing email, phone number, and physical studio address (if applicable).
   - *Visual rhythm:* Clean typography, distinct icons.

4. **The Inquiry Form (Main Focus)**
   - *Layout intent:* A detailed, multi-step or long-scroll form. Fields for names, wedding date, destination, budget, and vision.
   - *Visual rhythm:* Elegant input fields (subtle borders, nice focus states). The form should feel like a bespoke questionnaire, not a generic contact form.

5. **Office Hours & Availability**
   - *Layout intent:* A small text block detailing when the team is available to respond.
   - *Visual rhythm:* Muted text, placed near the submit button.

6. **FAQ Teaser**
   - *Layout intent:* Links to 2-3 common questions before they submit.
   - *Visual rhythm:* A subtle sidebar or block below the form.

7. **Social Links**
   - *Layout intent:* Large, clear links to Instagram, Pinterest, etc.
   - *Visual rhythm:* Minimalist icons.

8. **Map / Studio Location (Optional)**
   - *Layout intent:* A stylized, monochromatic map if there is a physical studio for consultations.
   - *Visual rhythm:* Low contrast to match the luxury aesthetic.

9. **Press/Partnership Inquiry Link**
   - *Layout intent:* A small, distinct link for non-wedding inquiries.
   - *Visual rhythm:* Muted, pushed to the bottom.

10. **Global Footer**
    - *Layout intent:* Consistent footer.
    - *Visual rhythm:* Standard layout.
