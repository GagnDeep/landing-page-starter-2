# Layout Blueprint: Contact Page

1.  `TopBar`: Mini notification bar for immediate contact info (Phone/Email) & 6AM-11PM availability.
2.  `MainNavigation`: Sticky header with logo, primary links, and a high-contrast "Book a Class" CTA.
3.  `PageHeader`: Title area ("Contact Us").
4.  `ContactIntro`: Welcoming text emphasizing readiness to help.
5.  `InfoGrid`: Grid displaying Phone, Email, Address (Burail, Chandigarh), and Hours (6AM-11PM).
6.  `WhatsAppButton`: Large, prominent button to start a WhatsApp chat directly.
7.  `ContactForm_Full`: Comprehensive form (Name, Email, Phone, Preferred Class Type, Message).
8.  `InteractiveMap`: Large embedded Google Map showing the exact location.
9.  `DirectionsText`: Written directions from common landmarks in Chandigarh.
10. `PublicTransitInfo`: How to reach the school via local bus or transit.
11. `ParkingInfo`: Details on where to park if visiting the office.
12. `ResponseTimePromise`: Text stating expected response time (e.g., "We aim to reply within 2 hours").
13. `EmergencyContact`: A specific number for urgent issues (e.g., for current students on the road).
14. `SocialMediaLinks`: Large icons linking to Facebook, Instagram, etc.
15. `BranchLocations`: (If applicable, though mostly focused on Burail).
16. `BookingWidget`: Embedded scheduling tool (e.g., Calendly) for consultation calls.
17. `FAQTeaser`: Link to the FAQ page for quick answers.
18. `Photo_Office`: Image of the physical office front for easy recognition.
19. `PreFooterCTA`: Subtle reminder to check out courses while waiting for a reply.
20. `Footer`: Comprehensive footer with links, detailed contact info, social icons, and legal disclaimers.
