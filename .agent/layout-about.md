# About Page Layout Structure

1. **Hero Intro:** Large portrait image with overlapping text.
2. **The Brand Story:** Generous text block detailing the journey from local boutique to digital presence.
3. **The Designer Focus:** Image and bio of Deepika.
4. **Our Craftsmanship:** 2-column layout detailing the tailoring and fabric selection process.
5. **Core Values:** Grid of icons and short text (Quality, Fit, Style).
6. **Boutique Gallery:** Grid of interior shots of the physical store.
7. **Call to Action:** Link to browse collections or book a custom fitting.
