# About Page Layout Map

## 1. Hero (`hero`)
**Intent:** Establish the heritage and prestige of Oasis Caterers.
**Rhythm:** Elegant typography over a subtle, slow-panning background image of a refined event setup.

## 2. Our Story (`our-story`)
**Intent:** Detail the origins and vision of the founders.
**Rhythm:** Long-form text block with wide margins, accompanied by an offset historical or foundational image.

## 3. Core Values (`core-values`)
**Intent:** Highlight the pillars of the business (e.g., Excellence, Discretion, Artistry).
**Rhythm:** 3-column grid with subtle icons and descriptive text, utilizing secondary background color.

## 4. The Team (`the-team`)
**Intent:** Showcase the key personnel (Executive Chef, Lead Planner).
**Rhythm:** Alternating left/right image and text blocks, styled like editorial profiles.

## 5. Pre-Footer CTA (`cta`)
**Intent:** Direct the user to inquire or view services.
**Rhythm:** Centralized, high-contrast block with a clear call-to-action button.
