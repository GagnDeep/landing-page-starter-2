# Layout Documentation: About Page (`/about`)

## Structural Intent & Visual Rhythm
The About Page is a narrative journey. It should feel like reading a beautifully typeset magazine article about the family's heritage. Heavy emphasis on typography, drop caps, and interleaved archival or atmospheric photography.

## Sections (20 Named Layout Blocks)
1.  **`About-01-GlobalHeader`**: Standard elegant navigation bar.
2.  **`About-02-PageTitleHero`**: Minimalist hero. Very large centered serif typography "Our Story". Generous top/bottom padding.
3.  **`About-03-HeroAtmosphericImage`**: Wide, cinematic image placed just below or behind the page title, setting the mood.
4.  **`About-04-TheBeginningText`**: Narrow text column for comfortable reading. Drop-cap on the first letter. Tells the origin story.
5.  **`About-05-ArchivalPhotoGallery`**: A 2-3 column masonry layout of vintage-styled or actual historical photos of the bakery.
6.  **`About-06-FounderQuote`**: Full-width block, muted background. Huge quotation marks, elegant serif quote from the founder.
7.  **`About-07-GenerationsTimeline`**: A vertical line connecting text blocks detailing the passing of the torch through generations.
8.  **`About-08-TimelineNode`**: Component layout for each era. Year, title, brief description, optional small image.
9.  **`About-09-OurPhilosophySection`**: Centered heading, followed by a 3-column grid explaining core values (Quality, Tradition, Community).
10. **`About-10-PhilosophyCard`**: Icon or small illustration, followed by a bold sans-serif title and descriptive text.
11. **`About-11-TheKitchenTour`**: Large, immersive image or video thumbnail showing the bustling kitchen environment.
12. **`About-12-KitchenStats`**: A row of 3-4 statistics (e.g., "30+ Years", "10k+ Custom Cakes", "100% Local Wheat").
13. **`About-13-MeetTheBakersHeader`**: Section title introducing the team.
14. **`About-14-BakerProfileGrid`**: Grid layout for key team members.
15. **`About-15-BakerProfileCard`**: Portrait image, name, role, and a one-sentence fun fact or specialty.
16. **`About-16-CommunityInvolvement`**: Text and image section highlighting how the bakery gives back to Patiala.
17. **`About-17-AwardsAndRecognition`**: A row of elegant badges or text listing local awards.
18. **`About-18-JoinOurFamilyCTA`**: Call to action leading to the careers page or contact page.
19. **`About-19-GlobalFooterMain`**: Standard footer structure.
20. **`About-20-GlobalFooterLegal`**: Standard legal footer strip.
