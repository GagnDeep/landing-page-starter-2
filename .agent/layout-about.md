# Layout: About Page
**Rhythm**: Narrative-driven, intimate, heavily reliant on photography and elegant type.

1.  **Global Navigation**: Sticky, translucent header.
2.  **About Hero**: Subtle, slow-moving atmospheric video or parallax image. Large centered serif title.
3.  **Mission Statement**: Full-width, solid muted background. Oversized, left-aligned typography.
4.  **Our Story (Origin)**: Split layout. Historical or origin image left, text right.
5.  **Our Story (Growth)**: Split layout. Text left, image right, but offset lower to break the horizontal line.
6.  **Our Philosophy Intro**: Centered heading, ample whitespace.
7.  **Core Values Grid**: 3-column grid of minimalist cards. Iconography or subtle typography focus.
8.  **The Artistry (Ingredients)**: Large banner image with parallax scroll.
9.  **The Artistry (Technique)**: 2-column layout, image-heavy on both sides with overlapping captions.
10. **The Studio Environment**: Full-width gallery slider. No text, purely visual.
11. **Meet the Founder**: Large portrait image dominating the left, biography text on the right.
12. **Team Introduction Header**: Centered typography.
13. **Team Grid**: 4-column grid of portraits. Hover states reveal names/titles elegantly.
14. **Community Involvement**: Split layout with a muted background block overlapping a vibrant image.
15. **Sustainability Commitment**: Narrow centered column for text, deeply engaging and readable.
16. **Awards & Recognition**: Minimalist list layout with right-aligned dates/orgs.
17. **Client Roster (if applicable)**: Horizontal scrolling marquee of subtle text or logos.
18. **Studio Location/Map**: Artistic, custom-styled map or atmospheric exterior photo.
19. **Call to Action (Consultation)**: Full-bleed dark mode section with glowing accent typography.
20. **Global Footer**: Centered, clean link directory.
