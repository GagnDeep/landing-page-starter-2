# Layout Documentation: Features (Services) Page

## Intent
Detail the specific services offered (Bespoke, Made-to-Measure, Alterations, NRI specific). It needs to be clear, structured, and visually distinguish the levels of service.

## Sections
1. **Hero:** Clean, modern image of different fabric swatches. Title: "Our Services."
2. **Service 1 (Bespoke):** Deep dive. Full width, multiple images showing the process from scratch. Highlighting the 50+ hours of work.
3. **Service 2 (Made-to-Measure):** Explaining the difference. Faster turnaround, pre-existing patterns.
4. **Service 3 (Alterations):** Breathing new life into old garments. Before/after subtle sliders.
5. **Service 4 (NRI Wardrobe Management):** Remote consultations, measurement profiles, global shipping.
6. **Comparison Table:** A refined, non-cluttered table comparing Bespoke vs. MTM.
