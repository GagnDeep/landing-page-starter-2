# Features/Services Page Layout Map

## 1. Hero (`hero`)
**Intent:** Introduce the breadth and quality of services offered.
**Rhythm:** Clean, minimalist header with a striking hero image of plated food.

## 2. Bespoke Menus (`bespoke-menus`)
**Intent:** Detail the custom menu creation process.
**Rhythm:** Split layout with a detailed text description alongside an interactive or parallax image.

## 3. Venue Partnerships (`venue-partnerships`)
**Intent:** List exclusive or preferred venue relationships.
**Rhythm:** Grid of venue logos or small images, cleanly spaced.

## 4. Event Styling (`event-styling`)
**Intent:** Explain additional styling and decor services.
**Rhythm:** Full-width image break followed by a 2-column text and image layout.

## 5. Pre-Footer CTA (`cta`)
**Intent:** Encourage booking a consultation.
**Rhythm:** Solid primary background color with large serif typography and a prominent button.
