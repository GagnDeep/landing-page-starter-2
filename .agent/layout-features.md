# Features / Services Page Layout Blueprint

## 1. Hero
- **Layout:** Split header, large text on left, compelling event imagery on right.

## 2. Core Service: Weddings
- **Layout:** Large section with a dedicated image gallery and a list of specific offerings (e.g., Live Counters, Traditional Sweets).

## 3. Core Service: Corporate
- **Layout:** Similar to weddings, but slightly more structured and formal in presentation.

## 4. The Menu Highlights
- **Layout:** A horizontal scrolling list of signature items.

## 5. Event Production
- **Layout:** A grid explaining non-food services (decor coordination, staffing, rentals).

## 6. CTA
- **Layout:** Banner inviting to view pricing or contact.
