# Features Page Layout Architecture (The "Why Us" Page)

## 1. Hero (`FeaturesHero`)
- **Intent:** Declare the unique selling propositions immediately.
- **Rhythm:** Bold, short headline. High contrast.

## 2. 24/7 Delivery Deep Dive (`FeatureDelivery`)
- **Intent:** Explain the logistics elegantly.
- **Rhythm:** Dark section. Split screen: map graphic vs. text.

## 3. Artisanal Quality (`FeatureQuality`)
- **Intent:** Prove the premium nature.
- **Rhythm:** Overlapping image collage with tight text blocks.

## 4. Customization Engine (`FeatureCustomization`)
- **Intent:** Show how easy it is to personalize.
- **Rhythm:** Step-by-step horizontal scroll or a staggered vertical layout.

## 5. Corporate Gifting (`FeatureCorporate`)
- **Intent:** Target B2B buyers.
- **Rhythm:** Clean, structured 2-column grid.

## 6. Footer CTA (`FeaturesCTA`)
- **Intent:** Start an order.
- **Rhythm:** Minimalist, high contrast.
