# Layout: Home Page
**Rhythm**: High impact, visually luxurious, spacious. Slower scroll velocity expected.

1.  **Global Navigation**: Sticky, translucent header with minimalist text links and a distinct CTA.
2.  **Hero Section**: Full viewport height. Asymmetric split: dominant, evocative background image with a floating, refined typography block offset to the left.
3.  **Hero Social Proof Strip**: A subtle, horizontal marquee of logos or minimal text immediately below the hero fold.
4.  **Brand Essence Introduction**: Centered, oversized serif typography block. Generous top and bottom whitespace.
5.  **Featured Categories Grid**: 3-column asymmetric grid. Alternating image heights to create a masonry-like feel.
6.  **Signature Artistry Spotlight**: Full-bleed section. Large, high-resolution background image with a dark overlay and a stark white, right-aligned typography block.
7.  **Testimonial Carousel**: Full width, light muted background. Large serif quotes with subtle, smooth sliding animation.
8.  **Process Overview (Step 1)**: Left-aligned image, right-aligned text block. Soft entry animation.
9.  **Process Overview (Step 2)**: Right-aligned image, left-aligned text block. Overlapping elements for depth.
10. **Process Overview (Step 3)**: Left-aligned image, right-aligned text block.
11. **Bestsellers Showcase Header**: Centered heading, subtle secondary text.
12. **Bestsellers Showcase Grid**: 4-column even grid. Cards with soft hover elevation and image scaling.
13. **Behind the Scenes Video Banner**: Full-width interactive video block. Parallax scrolling effect.
14. **Founder's Note**: Split layout. Intimate portrait on the right, letter-style typography on the left.
15. **Press/As Seen In**: Minimalist grid of greyscale logos on a muted background.
16. **Seasonal Collection Teaser**: Card-based overlapping layout. Dark mode card on a light background.
17. **FAQ Accordion Teaser**: Narrow, centered column. 3-4 highly relevant questions, elegant expansion animation.
18. **Newsletter Opt-in**: Full-bleed primary brand color background. Centered, large typography with a minimalist input field.
19. **Pre-Footer Navigation**: Multi-column link directory with subtle categorizations.
20. **Global Footer**: Centered logo, copyright, legal links. Clean and subdued.
