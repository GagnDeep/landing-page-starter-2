# Home Page Layout Structure

The Home page of Aura Boutique is designed to be an immersive, editorial experience that guides the user through the brand's premium offerings, custom stitching services, and latest collections.

## Sections (20 Distinct Layout Intents)

1.  **Global Notice Bar:** Topmost thin bar for shipping/discount announcements. High contrast text on primary color background.
2.  **Editorial Header/Navigation:** Transparent on load, transitions to solid glass-effect on scroll. Minimalist logo left, clean navigation center, icons (search, cart, user) right.
3.  **Hero Video Splash:** Full viewport height (`min-h-screen`). Slow-motion cinematic video of boutique fashion in the background. Large, elegant serif heading overlay, soft fade-in animation.
4.  **Brand Essence Statement:** Generous whitespace (`py-24`). Centered, large serif text expressing the Aura Boutique philosophy. Text reveals on scroll.
5.  **Featured Collection - Carousel Intro:** Split layout. Left: Sticky description of the current trending collection. Right: Horizontal scrolling carousel of large, high-res outfit images.
6.  **"The Art of Custom Stitching" Banner:** Full-width image background (tailor working). Parallax effect. Overlay text highlighting the core service.
7.  **Custom Stitching Process Steps:** 3-column grid (`grid-cols-1 md:grid-cols-3`). Minimalist line icons, short titles, and descriptions. Ample spacing between columns.
8.  **Lookbook Grid - Asymmetrical:** Masonry or asymmetrical grid layout featuring 4-5 key looks. Mix of portrait and square images to create visual interest.
9.  **Category Navigation - Visual:** Large circular or rounded-square image links (Ethnic, Western, Fusion, Accessories). Hover effect scales image slightly.
10. **"Boutique Favorites" - Curated List:** Clean, list-style layout (not a grid). Image on left, details on right. Alternate left/right alignment down the page.
11. **Founder's Note / The Designer:** Split layout (`grid-cols-1 md:grid-cols-2`). High-quality portrait of Deepika on one side, a personal letter/signature on the other. Warm, inviting tone.
12. **New Arrivals - Marquee:** Infinite horizontal scrolling text banner announcing "NEW ARRIVALS" separated by elegant star or diamond shapes.
13. **New Arrivals - Product Grid:** Standard 4-column product grid. Clean cards, no borders, subtle shadow on hover. Quick "Add to Cart" or "Customize" buttons reveal on hover.
14. **Customer Stories / Testimonials:** Full-width section with muted background. Large serif quotes. Minimalist slider to navigate between reviews.
15. **Instagram Shop Feed:** "Shop the Gram" section. 4x2 grid of square images pulling from Instagram aesthetic. Hover reveals shopping bag icon.
16. **Boutique Location Spotlight:** Split layout. Left: Map or stylized illustration of the Tripuri, Patiala location. Right: Address, opening hours, and "Get Directions" button.
17. **Sustainable/Quality Promise:** 3-column text-focused section highlighting fabric quality, local artisans, and sustainable practices.
18. **Newsletter Signup - Editorial:** Large, bold typography. "Join the Aura Inner Circle". Minimalist input field with a bottom border only, sleek submit button.
19. **Pre-Footer Links Grid:** 4-column layout for Shop, About, Services, and Help links. Small sans-serif text, generous line height.
20. **Global Footer:** Minimalist bottom bar. Copyright info, social media icon links, subtle legal links (Terms, Privacy).
