# Layout: FAQ Page
**Rhythm**: Organized, highly scannable, reassuring.

1.  **Global Navigation**: Sticky, translucent header.
2.  **FAQ Hero**: Clean, centered typographic header. "How can we help?"
3.  **Search Bar (Optional)**: Prominent, elegant search input field.
4.  **Category Anchor Links**: Horizontal list of tags to jump to sections.
5.  **Category 1 Header (e.g., Ordering)**: Left-aligned, bold serif typography.
6.  **Category 1 Accordion**: Clean, border-bottom separated accordion items.
7.  **Category 2 Header (e.g., Flavors & Dietary)**: Left-aligned header.
8.  **Category 2 Accordion**: Accordion items.
9.  **Mid-page Image Break**: Full-width, narrow parallax image slice to rest the eyes.
10. **Category 3 Header (e.g., Delivery & Setup)**: Left-aligned header.
11. **Category 3 Accordion**: Accordion items.
12. **Category 4 Header (e.g., Pricing & Payment)**: Left-aligned header.
13. **Category 4 Accordion**: Accordion items.
14. **Quick Links / Resources**: 3-column grid linking to Pricing, Features, Contact.
15. **Category 5 Header (e.g., Tasting Process)**: Left-aligned header.
16. **Category 5 Accordion**: Accordion items.
17. **Category 6 Header (e.g., Urgent Issues)**: Left-aligned header, perhaps highlighted in accent color.
18. **Category 6 Accordion**: Accordion items.
19. **Still Need Help? CTA**: Centered, warm block directing to the contact page.
20. **Global Footer**: Centered, clean link directory.
