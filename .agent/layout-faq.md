# FAQ Page Layout Map

## 1. Hero (`hero`)
**Intent:** Reassure the client that all details are handled.
**Rhythm:** Simple, text-focused header.

## 2. Categories (`categories`)
**Intent:** Organize questions by topic (Booking, Menu, Logistics).
**Rhythm:** Sticky sidebar navigation or horizontal tabs.

## 3. FAQ Accordion (`faq-accordion`)
**Intent:** Provide clear, concise answers.
**Rhythm:** Clean accordion list, expanding smoothly without jarring the layout.

## 4. Still Have Questions? (`contact-prompt`)
**Intent:** Catch edge-case questions and drive contact.
**Rhythm:** Small centralized block with a link to the contact page.
