# FAQ Page Layout Structure

1. **Page Header**: "How Can We Assist You?"
2. **Search Bar**: Minimalist search input for finding specific queries.
3. **Categories Sidebar/Sticky Nav**: Links to jump to sections (Orders, Sizing, Shipping, Bridal).
4. **Accordion Sections**: Cleanly animated accordions for Q&A, divided by category.
5. **Still Need Help?**: Contact call-to-action block.
6. **Footer**: Standard expansive footer.
