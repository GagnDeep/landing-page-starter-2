# Layout Intent: FAQ Page

## Core Intent
Address common customer concerns preemptively to reduce friction in the booking process, presented in a clean, easily scannable format.

## Key Sections
1. **Hero Header:** Simple title with a brief note encouraging contact if a question isn't answered here.
2. **Category Tabs/Links:** Quick jumps to sections like "Booking," "Fittings," "Pricing," "Delivery."
3. **Accordion List:** The core of the page, using smooth open/close animations to keep the layout uncluttered.
4. **Still Have Questions?:** A direct link to the Contact Page at the bottom.
