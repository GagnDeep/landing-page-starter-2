# Layout Intent: FAQ Page

**Goal:** Provide clear, reassuring answers to common questions without sacrificing the elegant, uncluttered design language.

## 1. Hero: Questions & Answers
- **Visual Rhythm:** Clean, text-focused header.
- **Layout:** Large, centered serif title with a brief, calming subtitle.

## 2. Quick Search
- **Visual Rhythm:** Functional, prominent input.
- **Layout:** A wide, elegant search bar to allow users to bypass scrolling if they have a specific question.

## 3. Category Navigation (Sticky)
- **Visual Rhythm:** Horizontal list.
- **Layout:** A sticky navigation bar that links to specific sections below (e.g., Booking, At-Home, Services, Policies).

## 4. Category Header: Booking & Appointments
- **Visual Rhythm:** Clear section break.
- **Layout:** A prominent, left-aligned heading with a subtle border or generous margin above it.

## 5. Q&A Block: Booking 1
- **Visual Rhythm:** Accordion / Disclosure.
- **Layout:** Question in bold/serif text. Clicking reveals the answer with smooth, deliberate motion. Thin line separator.
