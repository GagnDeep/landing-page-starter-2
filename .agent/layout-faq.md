# Layout: FAQ Page

1. **Hero Header:** "Frequently Asked Questions"
2. **Search Bar:** Simple input to filter questions.
3. **Categories Sidebar/Top Tabs:** E.g., Ordering, Sizing, Shipping, Care.
4. **Accordion List:** The questions and answers grouped by category. Ensure typography is highly legible.
5. **Still Need Help?:** Contact block linking to email and WhatsApp.
