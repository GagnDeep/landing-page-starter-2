# A2Zee Events - FAQ Page Layout Blueprint

## Overall Intent
To provide clear, authoritative answers to logistical and process-oriented questions, reinforcing the "hospitality-pro" persona.

## Structural Sections
1.  **`faq-hero`:** Simple, direct header.
2.  **`faq-categories-sidebar`:** Sticky left-hand navigation to jump between sections (Logistics, Investment, Destinations, The Process).
3.  **`faq-content-accordions`:** The main content area using the shadcn Accordion component for clean, accessible interaction.
4.  **`still-have-questions-cta`:** A warm invitation to reach out directly if a specific question isn't answered.
