# FAQ Page Layout Architecture

## 1. Hero (`FAQHero`)
- **Intent:** Clear, helpful, calming.
- **Rhythm:** Centered, simple typography.

## 2. Search (`FAQSearch`)
- **Intent:** Immediate utility.
- **Rhythm:** Massive, elegant input field taking up the center of the screen.

## 3. Categories (`FAQCategories`)
- **Intent:** Quick jumps.
- **Rhythm:** Grid of pill-shaped links or clean text links.

## 4. Accordion Lists (`FAQList`)
- **Intent:** The actual answers.
- **Rhythm:** Grouped by category. Very clean accordion UI. Thin borders.

## 5. Contact CTA (`FAQContactCTA`)
- **Intent:** Fallback if unanswered.
- **Rhythm:** Gentle, muted background block.
