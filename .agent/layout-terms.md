# Terms & Conditions Page Layout Map

**Goal:** Standard legal page. Clean, legible, and unobtrusive.

## Section 1: Header
- **Visuals:** Minimalist.
- **Structure:** "Terms & Conditions". Last updated date.

## Section 2: Content Body
- **Visuals:** Long-form text block with clear typography (Lato).
- **Structure:** Sections covering website usage, booking terms, payment policies, intellectual property, etc.
